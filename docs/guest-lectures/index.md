# Guest lectures

Standalone lectures the course team gives to other programs, each published with interactive slides, a PDF and numbered references.

* [Guest Lecture: Agentic AI Loops](agentic-ai-loops.md) - An interactive guest lecture for UNM's Ethical AI for Autonomous Systems course, written for a mixed technical and non-technical class: what agentic AI is, how it differs from predictive models and language models, and how sequence, selection and iteration explain the agent loop.
