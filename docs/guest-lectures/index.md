# Guest lectures

Standalone lectures the course team gives to other programs, each published with interactive slides, a PDF and numbered references.

* [Guest Lecture: Agentic AI Loops](agentic-ai-loops.md) - A 30-minute overview of agentic AI for UNM's Ethical AI for Autonomous Systems course, for a mixed technical and non-technical class: what it is, how it differs from predictive models and language models, and how sequence, selection and iteration explain the agent loop.
