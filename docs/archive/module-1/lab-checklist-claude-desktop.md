# Lab Checklist: Claude Desktop Orientation (Superseded)

!!! warning "Superseded"

    This page is kept for history. The current version is [Module 1 Activities](../../modules/module-1/activities.md).

The goal of this Lab is to help and guide the user to understand the agentic functionalities of Claude Desktop.

Provide screenshots of each completed step is pasted into a Lab Log document to be submitted.

## Setup and Navigation
- [ ] Create a sample folder on your Computer (e.g., Desktop)
- [ ] Download and install the [Claude Desktop app](https://code.claude.com/docs/en/desktop-quickstart){target=_blank}
- [ ] Locate (1) **Chat**, (2) **Cowork**, and (3) **Code** tabs

## Tasking Claude
- [ ] submit a **test task** via the **Chat** tab
- [ ] grant folder access to the sample folder in the **Cowork** tab, 
    - [ ] submit a **pre-written** test instruction to **Cowork** (e.g., create a text document in said folder containing the work you have carried out).
