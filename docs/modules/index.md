# Modules

The five course modules, each budgeted at eight hours: overview, foundational concepts, reading guides, activities, labs, chapter quizzes, and resources.

* [Module 1: From Prompts to Pipelines](module-1/index.md) - Thinking like an automation designer: what agents are, the automation spectrum, hands-on agent labs, and your Workflow Audit.
* [Module 2: Agent Reasoning Architectures and Tool Integration](module-2/index.md) - How agents reason and act: Chain-of-Thought, ReAct, Tree of Thoughts, LATS, tool integration with LangChain, prompt design, and trace evaluation.
* [Module 3: Memory Architectures and RAG](module-3/index.md) - Parametric and non-parametric memory, the six-stage RAG pipeline, conversational memory patterns, retrieval optimization, and RAGAS evaluation.
* [Module 4: Multi-Agent Systems](module-4/index.md) - Coordination architectures, LangGraph and CrewAI implementation, the three-role pipeline, and coordination-failure diagnosis.
* [Module 5: Responsible Agentic AI](module-5/index.md) - Production deployment, multi-dimensional evaluation, observability with LangSmith, OWASP Top 10 for LLM applications, and EU AI Act / NIST AI RMF governance.
