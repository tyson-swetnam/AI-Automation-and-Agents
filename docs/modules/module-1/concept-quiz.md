# Module 1 Concept Quiz

The Module 1 concept quiz checks the two foundational learning outcomes of the
module - **LO 1.1** (what an AI agent is and how it differs from a chatbot, a
script, an API call or a search engine) and **LO 1.2** (the agent loop and the
automation paradigms) - with 15 auto-graded questions in about 20 minutes.

| Part | Questions | Format | Points |
| :-- | :-- | :-- | :--: |
| A - Multiple-choice definitions | 1-6 | One correct option per question | 1 each |
| B - Scenario classification | 7-11 | Classify a described system or task | 1 each |
| C - Sequencing | 12-15 | Drag items into the correct order (full credit only when the whole sequence is right) | 1 each |

Total: 15 points. Every question is tagged with the learning outcome it
assesses, and you get feedback on each answer as soon as you submit.

## Before you start

- Take the quiz after you have finished the
  [Module 1 foundational concepts](foundational-concepts.md) and their
  [chapter quizzes](chapter-quizzes.md); it assumes the vocabulary from all
  five chapters.
- In the course's grading rules the concept quiz is **formative**: you have
  **two attempts** in the LMS and your **best score is retained**. It does not
  carry a numeric weight in the Module 1 grade (the
  [Workflow Audit Project](activities.md) does).
- The copy embedded below is for practice. It grades **entirely in your
  browser**; nothing you enter is transmitted or recorded anywhere, and you
  can retake it as often as you like. Your attempts in the LMS are what your
  instructor sees.

??? note "About the answer key"

    The quiz is a single self-contained HTML file with no server behind it,
    so its answer key and per-question rationale are embedded in the page's
    own JavaScript, exactly as they are in the public course repository, and
    the current version also prints an *Instructor Answer Key & Rationale*
    table at the bottom of the page. That is by design - the quiz is a
    self-check, not a proctored test - but it is also why the graded attempts
    live in the LMS. Answer every question before you scroll down, and use
    the key to learn from your mistakes, not to skip the thinking.

## After the quiz

Note the learning outcome tags on any question you missed. For LO 1.1 gaps,
re-read *Chapter 1: Redefining Intelligence* in the
[foundational concepts](foundational-concepts.md); for LO 1.2 gaps, re-read
*Chapter 2: The Automation Ecosystem* and the agent-loop section. Then
continue to the [Module 1 activities](activities.md).
