# Module 1: From Prompts to Pipelines

Thinking like an automation designer: what agents are, the automation spectrum, hands-on agent labs, and your Workflow Audit.

* [Module 1 Overview: From Prompts to Pipelines](overview.md) - Introduction to Module 1 (8 hours): what an AI agent is, the perceive-plan-act-observe loop, the no-code/low-code/code-first automation landscape, learning objectives, unit checklist, grade weights, and the diagnostic self-survey.
* [Module 1: Foundational Concepts](foundational-concepts.md) - Five-chapter conceptual lesson for Module 1: what AI agents are, the no-code/low-code/code-first automation spectrum, AI literacy frameworks, workflow decomposition and two-dimensional automation assessment, and responsible AI governance.
* [Module 1 Reading Guides](reading-guides.md) - Reading guides (sources, key terms, guiding questions, critical-thinking prompts) for the five chapters of Module 1, From Prompts to Pipelines.
* [Module 1 Activities](activities.md) - Activity guide for Module 1: ungraded self-check prompts, two hands-on labs (running Llama 3.2 locally with Ollama and delegating file tasks to an agent via Openwork), the Workflow Audit project with mapping template and assessment matrix, and the peer discussion.
* [Module 1 Chapter Quizzes](chapter-quizzes.md) - Five self-evaluating five-question chapter quizzes with collapsed answer keys and per-option feedback for Module 1, From Prompts to Pipelines.
* [Module 1 Concept Quiz](concept-quiz.md) - A 15-question auto-graded concept quiz on Module 1 learning outcomes 1.1 and 1.2 (definitions, scenario classification and sequencing), graded in your browser, with a full-screen version and a printable PDF.
* [Module 1 Diagnostic Knowledge Survey](diagnostic-survey.md) - The 12-question, ungraded pre-instruction survey that captures your current mental models of agents, automation paradigms and Python comfort before Module 1 begins, and whose final question seeds the Workflow Audit.
* [Module 1: Additional Suggested Resources](resources.md) - Curated supplementary notes for Module 1 covering generative AI foundations, agent types, development tooling, what distinguishes an agent from chatbots, APIs and scripts, the ReAct loop, and automation paradigms with low-code examples.
* [Module 1 Readings](readings/index.md) - Course reading packages for Module 1.
* [Module 1 Worksheets](worksheets/index.md) - Fill-in worksheets used in the Module 1 activities (drafts under construction).
