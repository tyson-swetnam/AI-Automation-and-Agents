# Module 1 Readings

Course reading packages for Module 1.

* [What Is an AI Agent?](what-is-an-agent.md) - Module 1 reading package contrasting LangChain's engineering definition of an agent with Wooldridge and Jennings' (1995) theoretical definition, ending with a 12-term glossary pre-fill worksheet and synthesis questions.
* [AI Automation and Multi-Agent Frameworks: A Strategic Comparison](automation-and-multi-agent-frameworks.md) - Reading that compares the no-code and low-code automation platforms Zapier, Make and n8n with the developer-centric multi-agent frameworks CrewAI and LangChain/LangGraph, and maps them onto an AI maturity roadmap.
* [Intelligent Agents: Theory and Practice (Reading Summary)](intelligent-agents-wooldridge-jennings.md) - Student-oriented summary of Wooldridge and Jennings (1995): the weak and strong notions of agency, the four pillars of agent behavior, intentional systems, and how agents differ from objects and processes.
