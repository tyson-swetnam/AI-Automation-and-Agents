# Instructor materials

This folder holds the worked solutions to the course's lab notebooks. It is
public, like the rest of the repository, but it is deliberately **not** part
of the course site: nothing here is rendered, mirrored as Markdown, or listed
in `llms.txt`, and no learner-facing page links to it. The course owners
decided on 2026-09-11 to keep the solutions open on GitHub on those terms.

| [`materials/module5/Module5_Instructor_Solution.ipynb`](materials/module5/Module5_Instructor_Solution.ipynb) | [`docs/materials/module5/Module5_Learner_Starter.ipynb`](../docs/materials/module5/Module5_Learner_Starter.ipynb), the Module 5 lab |

GitHub renders each notebook with its saved outputs. To run one, open it in
Colab:
[Module 4](https://colab.research.google.com/github/tyson-swetnam/AI-Automation-and-Agents/blob/main/instructor/materials/module4/Module4_Instructor_Solution.ipynb),
[Module 5](https://colab.research.google.com/github/tyson-swetnam/AI-Automation-and-Agents/blob/main/instructor/materials/module5/Module5_Instructor_Solution.ipynb).

Modules 2 and 3 have no separate solution: their learner notebooks are
scaffolds whose assessed work is the learner's own extensions and written
observations.

**Keep each solution in step with its starter.** A solution's header cells
(title, time budget, learning objectives, submission filename) mirror its
starter's, so when one changes, change the other in the same commit.

The course site's
[instructor materials page](https://tyson-swetnam.github.io/AI-Automation-and-Agents/course-design/instructor-materials/)
covers the answer-key policy, how to configure the LMS, and how to mark a
page as verified.

If you are a learner, work from the starter notebook on your module's lab
page; that is the version the activities page assesses.
